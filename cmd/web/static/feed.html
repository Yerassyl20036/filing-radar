Latest SEC filings

Filing radar reads every new SEC filing within about a minute of EDGAR accepting it and labels it high, medium, low or routine with plain rules. A language model scores each 8-K and writes a short note on the important ones; every claim in a note quotes the filing, and code checks each quote word for word. It's a side project showing a reliable AI pipeline running on three free 1 GB servers. Important shows medium and up.
