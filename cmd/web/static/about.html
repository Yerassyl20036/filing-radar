About

Filing radar is a side project by Yerassyl Maratov, a backend engineer based in Kazakhstan. It's built to show how to put a language model into a production pipeline people can trust: rules first, every model claim checked against its source, a hard daily budget, and everything observable.

How it was built

Yerassyl designed and directed it; Claude Code was the main developer and wrote it in about three days. Every stage was reviewed, tested and deployed through a manual pipeline. The measured development cost is on How it works.

Stack

Go, PostgreSQL, Temporal, DeepSeek (swappable for Gemini, Groq or Claude), Caddy, Docker, GitHub Actions, and three Oracle Cloud free-tier servers.
